## 版本与证据强度

AllGatherMatmul 和 QBMM 的实际第一父版本源码以 Git 对象和旧 hunk 逐行校对。其他 EX 按固定修复提交的旧侧删除行、上下文和原 PR 文件载荷定位。EX-04、EX-12、EX-15、EX-34 和 EX-36 的必要消费段另外用固定文件及完整 patch 反向核验。另核对了 IsFinite 旧取源和 EX-29 的 V2 调用。ScatterNdAdd、Quadric 的补充证据单独引用，设备现场结论按原材料限制。FM-06 保留归档陈述级证据。

根动作和下游效应沿同一链计数。两版 ScatterNdAdd 不增加家族数，EX-12 的两个历史检索入口只记录一次事件。在本批记录各对能复用的范围。目录版本为 MECH-v0.3。[同动作与同失效关系](mechanism_equivalence.json)
