# P2 与 L1 的跨算子双轮读件

两案的实际修复父提交、旧侧补丁和 15 个原件节选在两个上下文读件前固定。预设答案先经第三个独立上下文复核，保管在读件检出目录之外。两轮只接收原件、受评范围、冻结提示和七条机理定义。两轮回执都没有工具事件，提交锁定后按原承诺揭封，再独立判卷。按 329 个项目暴露键核对家族和已知变体。公开事件的训练暴露未测量，成绩登记为流程演练。

| 案例 | 决定性动作 | 两轮 |
| --- | --- | --- |
| V411 vLLM NIXL MoE adapter | 固定旧版以 `-1` 表示无专家路由。映射 helper 从正确的 `topk_ids` 取得 `-1` 并当成普通张量下标，选到最后一个有效专家。在受评调用中，实际提交给 `dispatch` 的 ID 为 `[7,4]`，约定为 `[-1,4]`。证据止于 adapter 的交接边界。[vLLM #64086](https://github.com/vllm-project/vllm/pull/64086) | P2 各 1/1 |
| V412 PyTorch CUDA adaptive_max_pool2d.out | 固定旧包装层保留同形转置 `out` 的步长 `(4,1,2)`。旧 GPU 内核对该视图的裸指针以密排公式写最大值，把 `(0,0,1)` 写到相对基址第 1 个元素，应为第 2 个。索引输出独立且连续，此处计一个值输出写回动作。[PyTorch 固定修复](https://github.com/pytorch/pytorch/commit/31cf3d6aad86a77a0c9459cfcda947197f84ca59) | L1 各 1/1 |

两轮均为严格案 **2/2**，叶级、具体动作、因果角色、独立根各 **2/2**，零误计和漏计。A2 的另一独立算子是此前的加权交叉熵。A3 的另一独立算子是此前的 MPS SDPA。V412 直接从原输出指针追至旧写入，证据包括未正规化的输出视图和准确的实际存储表达式。本轮为固定源码静态验证。

揭封后登记 11 个入批谱系键，另保留策展时已看过的同源改动和未入批材料。由 329 个旧键合并到 347 个，供下一批去重。
