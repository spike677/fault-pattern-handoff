# A4 新事件双轮读件

主批五个独立事件家族在项目暴露清单中无交叉。每轮只收到编号原件、受评范围、七条目录和冻结读件提示。参考由整理者拟定，经另一模型上下文复核后承诺，B 保存在读件检出目录之外。两轮读件使用同一模型配置和输入，独立的临时上下文均没有工具事件。两轮输出锁定后按原承诺揭封，另一上下文独立复核。公开事件的训练暴露未测量。评估登记为流程演练，未设外部保全见证。

两批共六个家族，揭封后将 36 个家族、事件、补丁和缺陷系谱键写入开发暴露清单。原冻结输入含 293 键，下一批去重清单含 329 键。

## 附批 V404

附批独立使用 ONNX Runtime CPU ReduceSumSquare-18。旧依赖锁定的 ONNX v1.19.1 规定空 axes 与 `noop_with_empty_axes=1` 仍须对数据平方。旧快速路径正确读取空轴和标志，把只跳过轴归约扩大为整个算子的恒等拷贝；对 `[-2,3]` 写出原值，约定为 `[4,9]`。封存参考为 P2。事后复核按 P2 的冻结必要条件查验，实际已识别特殊状态，没有把它作为普通有效数据消费。修订参考为已证目录外，保留一个主动作。[ONNX Runtime #26436](https://github.com/microsoft/onnxruntime/pull/26436)
