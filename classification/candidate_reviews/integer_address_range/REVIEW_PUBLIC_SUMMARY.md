# 整数地址表示范围：公开审查结论

状态：**DECIDED / NEW_CANDIDATE**。正式新增模式 **0**。

合法坐标的精确整数关系在到达地址消费者前因表示范围不足而失真，可以在单位
换算和布局关系正确时发生。现有 L2、L1 和 NUM-01 均不能完整表达这一必要关系。
详细定义、排除条件与计数原则见 [候选卡](MODE_CARD_CANDIDATE.md)。

本轮审查三个已开发暴露家族的四个动作：GridSampler 前向 gather、反向 scatter
分开计根；NLLLoss2d backward 和 FlexAttention tile 偏移分别审查。GridSampler
C=521 对照中两个乘积可表示，首损失发生在加法；C=520 对照仍保留整数值。
泛型整数提升后窄写与 AVX2 窄加法的实际类型规则分别核查。

FlexAttention 测量版恢复至 `344609ab170a040fe5cfec74eac8db66cd344b6f`，但独立
复现布局、测量版布局和后来补丁未拼成同次运行证明。生成内核、实际 allocator
stride 和部分 backend 配置仍未取得。没有独立无符号真实正例的验证结论。

本地结果：**18/18 算术与语义边界控制、18 项固定源码断言通过**。原设备算子
重新执行 0 次。补码回绕只用于模型化报告中的表示损失；C++ 有符号溢出并不
因此获得定义为回绕的语言语义。

公开控制覆盖合法最大偏移、中间乘法/加法失真、事前与事后宽化、对象越界但
整数未失真、单位混用、漏基址、错误值未消费、不同地址动作及浮点状态近邻。
[控制代码](../../reliability_v044/public_controls.py) 可独立运行；源码断言依赖
本地固定源证据包，未把原件复制到此次公开提交。

NEW_CANDIDATE 表示值得进入正式准入流程。九条目录、判定器和评分器保持不变。
正式准入还需独立复核必要条件与近邻，并用未见事件验证；本轮三个家族不能
重复作为该验证的未见分母。
