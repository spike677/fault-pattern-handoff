# 锁后评分口径 v2

先按同一 A 的原件做一对一配对。原封存参考、复核修订及补证分别绑定 SHA。评分同时报告以下分母和分子。

| 维度 | 核对方式 |
| --- | --- |
| 事实与版本 | 合同、实际分支、来源和断言由独立复核判断。 |
| 具体动作 | 在有明确首错的参考动作中，判断是否描述出相同违约操作。 |
| 违反关系 | 在参考可确立缺陷的动作中，判断是否说明被破坏的计算或执行关系及其消费。 |
| 模式归属 | 程序比对参考允许的叶级、上位、目录外、合规或缺证；有据命中还需事实及锚点通过。 |
| 因果关系 | 核对有据角色与上游身份。参考允许无主次时，多个有据根可互换首要标签。 |
| 独立计数 | 按每个参考根报告确认正确、误计、漏计。下游和正常消费者计数为零。 |

同时报告严格完整案、缺证保留、错误弃权、目录外命中、错误肯定、错误排除和引证有效性。严格完整案要求全部匹配、必要证据与语义、模式、因果及计数通过。首错描述正确可单独给动作分。每个失败条目注明首要归因和原件依据。原分使用当时冻结口径，其中原试验两轮各 2/13。v2 增加了语义关系维度，严格分使用 v2 规则；同一参考内的具体动作、模式、因果和计数指标仍逐项报告。
