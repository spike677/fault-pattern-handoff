## 三处问题的处理

**ORT 的证据断点已经补齐。** 固定 v1.13.1 源码确认 `py::array` 通过 `ptr()` 原样转发到数值复制 helper，再由 CUDA 回调消费连续字节范围。本轮单列审查包支持 L1 和一个独立根。原 A 的未补证回放仍保留证据不足。

新增 [reviewed_static.py](reviewed_static.py) 核对合同、入口、转发、实现和消费者五段证据的类型、版本与内容摘要，再绑定至已有未知动作。它是人工审查后的绑定入口，不自动发现调用链，也不以结构校验替代事实解释审查。原始捕获包不被修改。

**RotaryEmbedding 的重复主张已修复。** 当同一动作的参数违规与泛化缺陷主张具有相同决定性证据，判定器保留有据参数上位并记录被归并的泛化主张。来源不同的竞争主张保留机理未决。根动作仍独立于叶级机理是否确定进行计数。地址类已证目录外的负向对照保持原结果。

**MIGraphX 保留有据数值上位。** 已核旧版 parser、方差改写、GPU pass 顺序、低精度改写和 precision propagation。尚缺实际故障内核的中间及累加工作精度，以及绑定该路径的同精度对照，故未升级为 NUM-02。CPU 算术对照不登记为 GPU 复现。

整数地址表示范围已核对 GridSampler，以及 NLLLoss2d 和 FlexAttention 两个不同算子的报告与固定源码，完成安全范围与越界表示的算术对照。本轮仅形成候选审查，正式新增模式为 0。两个新增审阅家族及相关谱系均已登记开发暴露。
