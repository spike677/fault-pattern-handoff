# MECH-v0.4 同一原 A 的分类稳定性复验

以 `e4e8fa9` 为因果修订基线，连续验证了 `8694ee9`、`80c8752` 和 `dea1d10`。三个候选只修改通用读件提示。每版使用两个全新的无工具上下文读取同一份 A，材料含 13 个已开发事件家族、37 个原件视图。两轮预测锁定后，Work 按原 B 判卷并逐字节复算。原分和新分分别保全。[读件提示](PROMPT.md) · [冻结与成绩摘要](STABILITY_RUNS.json)

## 8/14 的来源及修订

因果修订前后的第二轮相比，ggml、MIGraphX 和 RotaryEmbedding 各失一项，Qwen 补回一项。对同一批锁定事实交叉运行修订前后的判定器，三个失分案的机理标签一致。差异来自重新读件时证据的提交方式和作用域。Qwen 的旧事实另外证实，因果修订可把有据的 C3 下游机理归回同一个根。

| 案件 | 复现的断点 | `dea1d10` 双轮结果 |
| --- | --- | --- |
| Qwen | 静态合同事实引入另一快照的报告，缺同域旧行为。 | 同域证明闭合带偏置尾部的保存与下一块重复消费。两轮均为 C3、一根。 |
| ggml | 读件识别窄态更新与末端消费，逐条推导缺合同锚点。首版提示又让概述性报告覆盖了可用的旧循环。 | 同版 K 项、运行槽、末端实际消费者和同项同序对照闭合。两轮均为 NUM-01、一根。 |
| MIGraphX | 算术反例能证明指定同精度下的公式差异，旧 GPU 路径的实际工作精度缺绑定。 | 两轮均确认原始矩差消减、实际归一化消费和一根。NUM-02 叶级缺证。 |
| RotaryEmbedding | 旧构造器静态域使用另一快照的合同引文。 | 两轮均确认入口拒绝合法四维省略，归参数上位、计一根。旧路径止于参数检查，未发生 P2 所需的普通头数消费。 |

提示依次补充同域逐事实锚点、优先保留能闭合机理的固定静态证据，以及合规和适用性边界的零根提交流程。单例连续性在 `80c8752` 第一轮曾因把明确合规依据标成观察而退为缺证，`dea1d10` 两轮均恢复合规零根。MPS 的未证写入双轮保持缺证零根，GridSampler 双轮各确认两个无主次的独立根。[通用提示](PROMPT.md)
