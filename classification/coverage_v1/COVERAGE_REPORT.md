## 关键边界

- TransformerEngine 固定旧侧显示排序及保留前缀，报告者预期的 `-1` 跳过语义缺同版合同。原封存 P2 和事后缺证均可复算。
- Quadric、TensorFlow 图像反向、ScatterNdAdd、PyTorch 标量 `setitem` 补证保持原家族。补入的同版合同、消费者、写回或自动微分定义扩大了可判范围。
- PadV3Grad 的 N23 原件表明 `IsCut` 跳过必需的边界复制梯度，归入 C2。RMSNorm 仍缺把非连续视图与旧写入公式绑定的证据。
- SGLang DSPARK 的双轮原独立首读均未输出 C3，开封后回归双轮识别。NumPy `add.at` 固定例中的同值同址更新来自不同逻辑源，各计一次。
- C1 在原首读区分了 ORT 归一化抵消这条近邻。llama.cpp 同算子的 FP16 累加原两轮失分，因此当前成功近邻仅一条。C2 的 OpenVINO 历史项两轮过排，NumPy GCD 的真实短路对照也两轮输出缺证。
- PyTorch `cross_entropy` 的 C1 保留下游关系，P2 为独立根动作。叶级观察与根角色家族数分别登记。

## A4 新家族

QAT ConvBn2d 的同源卷积偏置和 FSDP 的同源梯度副本给出两个 C3 算子。FSDP 的 FULL_SHARD 溢出对照双轮准确区分，见同算子报告。

Caffe2 读取错误上限参数键形成 P1 根动作，低分提议实际写出形成 C1 下游。ORT FP16 分组卷积的写端和读端各证实一条 L2，事件家族仍计一个。近邻按原件和揭盲判卷登记。

V404 ReduceSumSquare 独立附批双轮均识别空轴快路径跳过逐元素平方。按冻结目录，旧实现正确识别特殊分支，错误落在该分支的求值范围。封存 P2 标签两轮各 0/1，审计目录外标签两轮各 1/1。两轮均漏引特殊分支仍需平方的决定性合同，有据机理、完整案件和 P2 近邻区分均失分。“同一事实和动作”稳定表示两轮重复了相同的证据缺口。最初未生成评分的格式失败记录属于同一事件。
