# 有限输入的中间浮点溢出

研究决定为 KEEP_CANDIDATE。适用关系和候选均按固定路径取证。

**正确约定** 适用有限输入存在可接受且可表示的目标结果，活跃路径的中间表示和运算顺序应允许该结果到达消费者。

**错误动作** 先做可避免的放大，或选用范围不足的中间格式，再消费生成的 Inf 或错误值。

**失效机制** 首个活跃中间值越过实际格式有限范围，后续乘零、归约或回写无法恢复约定值。

**七条边界** DropOutV3 仍取零掩码，有限值先溢出。FSDP 两个互斥分片各贡献一次，需分别排除 C1 和 C3。

## 子型

- **先放大再中性化**（FM-17）。有限 x 且 mask=0 时先算 x*scale，结果可能由 0 变 NaN。
- **实际累加器范围不足**（FM-28）。FM-17 的检索子型，尚无固定历史正例。
- **中间值窄化后在合并前溢出**。V406 是局部 FP16 平方首次超范围。

## 已核固定材料

- **FM-17** CASE-0097-M1，STATIC_ROOT。先算 x*scale 再乘零掩码，避免溢出的另一顺序在补丁中可对照。有界 x*scale 超过 FP32 有限范围而产生 Inf，后乘 0 得 NaN。旧语句直接将异常写到 outputGM。原始 x 已 Inf 以及 keep=0 的其他分支各自另核。 [FM-17 原件](https://gitcode.com/cann/ops-math/merge_requests/1589)
- **FM-28** 历史原代表待核，UNRESOLVED_OLD_PATH。历史候选描述累加中间量超过内部格式范围。无有据的实际累加器范围及第一次溢出更新。V406 的 pow 在 SUM 之前，E06 证明窄更新类型但未固定首溢出输入，均不作 FM-28 已证案例。

## 近邻和边界

- **V406** 溢出发生在平方而非累加中，不能当作 FM-28 正例。旧范围和具体数值经静态重算。V405 不同事件的完整副本重复是 C3，分开使用。 [V406 原件](https://github.com/pytorch/pytorch/pull/90028)
- **EX-24** 输入已非有限的传播错误不属于有限输入制造 Inf。原 Cdist 的适用动作限此固定 NaN 路径。 [EX-24 原件](https://gitcode.com/cann/ops-math/merge_requests/2743)
