# MECH-v0.4 模式卡索引

目录 JSON 保存九条模式的定义、语义角色、合同、决定性事实、可采证据和近邻排除。下表将每张卡连到已审案例或回归及可执行触发条件。[正式目录](catalog.json) · [注入规格与对照](INJECTION_PROTOTYPE.md)

| 模式 | 判据与典型材料 | 测试触发条件 |
| --- | --- | --- |
| P1 参数来源误读 | 实际读取另一语义角色的参数，如排序前与排序后上限。旧七类的 P1 例证见目录。 | 设置两个合法槽值为 1 和 2，只替换读取槽。 |
| P2 特殊参数状态误解释 | 参数读取正确，解释后的默认、显式或特殊状态违反同版约定。旧七类的 P2 例证见目录。 | 同测省略、显式 `-1` 和等效正索引。 |
| L1 错误采用连续布局寻址 | 非连续对象实际走密排寻址，逻辑坐标映射改变。旧七类的 L1 例证见目录。 | 对合法转置视图替换 stride，记录真实偏移和目标写入。 |
| L2 寻址单位换算错误 | 把元素、字节或位的换算弄错，如 RepeatInterleave 实际轴的窗口偏移。 | 固定 16 位打包元素和索引 1，比较两个偏移与返回值。 |
| C1 无效计算项纳入 | 无效成员真的参与了计算。旧七类的 C1 例证见目录。 | 只解除第三项的资格排除，再以中性值对照输出。 |
| C2 必需计算项遗漏 | 受评合同要求的成员未实际写回或累加，如补齐写回证据后的 ScatterNdAdd 两处。 | 只跳过必需的 B 项，检查 B 的重数由 1 变为 0。 |
| C3 同源计算项重复计入 | 同一个逻辑源在同一目标的重数超出合同，如作者确认的 Qwen 分块解码同一偏置。 | 重放相同源 B，另测值相同但身份独立的 C。 |
| NUM-01 运行累加状态过窄 | 同一累加状态在相邻更新之间保存到过窄类型，失真继续被使用。已审 llama.cpp CPU Flash Attention 和 Qdrant AArch64 Dot。 | 对 `[2048,1,1]` 比较逐次 FP16、FP32 保留状态和允许的末端转换。 |
| NUM-02 原始矩差求方差的有限精度消减 | 原始二阶矩减均值平方使本可保留的小方差消失，差进入归一化。已审 ONNX Runtime CUDA SkipLayerNormalization 和 JAX CPU standardize。 | 对高偏置近常量 FP32 行比较原始矩差与中心二阶矩，再以条件良好的行对照。 |

每个真实案例仍以定版合同、首错、消费者和调用证据为准。已证明的上位机理或目录外缺陷可以保留，证据不足时记录缺项。数值模式的准入报告列出适用路径、真实家族、合法对照和实际运行范围。[七类历史回归](../V04_IMPLEMENTATION_REPORT.md) · [数值模式准入](ADMISSION_REVIEW.md)
