# MECH-v0.4 正式目录读件

仅依据随答卷下发的 A 原件和正式目录裁决。逐案找出适用约定、固定版本实际路径、首个失真动作及其消费者。每个可判定的动作采用适当的证据等级、引用精确行范围并说明推导。输入存在独立证据范围时分别声明。动作角色和证据等级必须独立判定。

对报告级结论，用作用域内的作者确认独立支持每条决定性事实。对静态结论，分别引用与旧实现版本相符的适用约定和旧行为，旧行为须覆盖所评路径。其他快照的有效引文可以作为背景记录，决定性证明仍须在相应作用域内闭合。若跨版本条款实际适用，先记录已证的版本绑定。

对 NUM-01 与 NUM-02，逐项使用目录卡给出的必要事实键。宽累加对照与中心方差对照须保持同一批数据、逻辑项和适用语义。NUM-01 定位相邻更新间的窄状态写回、读取与失真。NUM-02 定位原始矩差、相同工作精度保留方差的对照以及输出消费。适用合同、具体动作和关键事实分别绑定各自的旧行为锚点。保留确有证据的合法末端舍入和可接受近似。已证的单次归约前平方溢出按原证据保留，使用 `established_other_defect` 且有据时填写 `pre_reduction_square_overflow`。

对于已被正式目录覆盖并可举证的机理，填写对应事实。只有能证明属于其他机制时，才使用 `established_other_defect`。如果材料不足，交出明确的待判动作和缺证依据。已给信息只足以描述语义行为时保留 `unknown` 因果角色。正常消费者放入支持记录。以 JSON schema 返回动作、事实、支持操作和范围说明。
