# MECH-v0.4 离线注入规格与原型

每条规格在同一输入和配置下执行基线、单点注入与恢复三次调用。输出给出调用 ID、命中位置、中间轨迹、参考结果与五项布尔检查。离散结果须相等，NUM-02 使用绝对误差限 `1e-4`。地址类的访问受缓冲区约束，L1 另检查前后哨兵。

```text
python -B -X utf8 classification/mech_v04/injection.py
python -B -X utf8 classification/mech_v04/injection.py --mode C3
```

| 模式 | 单点动作及触发 | 中间值与预期输出 |
| --- | --- | --- |
| P1 | 排序时将排序前上限槽换成排序后上限槽。设两槽为 1 和 2。 | 属性名改变，分数 `[9,7,5]` 的输出从 `[9]` 到 `[9,7]`。 |
| P2 | 将 EmbeddingBag 显式 `-1` 解读为省略。表为 `[3,5,9]`，索引为 `[0,2]`。 | 排除索引 `2` 变为无排除，和从 `3` 到 `12`。 |
| L1 | 把合法转置视图的真实步长 `(1,2)` 换成密排步长 `(2,1)` 写入。 | 坐标 `(0,1)` 的元素偏移从 `2` 到 `1`，逻辑输出从 `[1,3,2,4]` 到 `[1,2,3,4]`。 |
| L2 | 访问小端 16 位元素时直接使用元素索引 `1` 作为字节偏移。 | 偏移从 `2` 到 `1`，结果从 `0x3344` 到 `0x4411`。 |
| C1 | 使掩码不允许的源 C 参与求和。三项值为 `[3,5,99]`。 | C 的计入次数从 0 到 1，和从 `8` 到 `107`。 |
| C2 | 跳过源 B 的必需更新。三项 A、B、C 的值为 `[2,5,7]`。 | B 的计入次数从 1 到 0，和从 `14` 到 `9`。 |
| C3 | 将来自同一源 B 的值 `4` 再提交一次。源 A 的值为 `3`。 | B 的计入次数从 1 到 2，和从 `7` 到 `11`。 |
| NUM-01 | 对 `[2048,1,1]` 逐项累加，在更新之间用 FP16 保存运行状态。 | 第二轮精确和 `2049` 被存为 `2048`，第三轮读取该值，输出从 `2050` 到 `2048`。 |
| NUM-02 | 对 `[8191,8193,8191,8193]` 用原始矩差取代中心二阶矩，固定 FP32 运算及 `epsilon=1e-5`。 | 方差从 `1` 到 `0`，同一归一化消费者把输出绝对值从约 `0.999995` 改为约 `316.22777`。 |

恢复调用须重现基线的输出、机理轨迹和未命中状态。回归覆盖相等参数槽、显式正索引、连续布局、单字节元素、中性项、新来源的相同数值、允许的末端降精度和条件良好的方差输入。当前执行环境为标准库 Python 的合成 CPU 原型，生产算子和设备注入登记为 `NOT_TESTED`。[原型入口](injection.py) · [合规对照](../test_mech_v04_injection.py)
