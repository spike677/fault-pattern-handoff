## 术语、四项依据和案例表达

术语表给有效输入元素、求和项／比较候选值、局部梯度项、原始分片结果、逻辑计算项、重复计入各列了对象边界、来源和反例。七张模式卡逐一记录语义依据、分类依据、参考关系和验证依据。L1 的采纳实例是 Concat 中只有行起点错误地假设密排，回归仍判 L1。FP-B16 仅作为出参写回的近邻，该 Concat 输入路径由自身源码支持。[术语表和逐卡依据](../classification/TERMS_AND_REFERENCES.md)

API42 用于核查参数结构、角色和约束，V4 的 Requires、Skip、构造和参考案例用于组织模式卡及近邻。将它们各自的输入条件、触发编号和计数保留为独立轴。案例按“对象与约定 → 具体动作或待核 → 版本及作用域 → 模式和近邻 → 因果角色 → 证据边界”摘要。N24 的两次错误即使症状相同，也能按实际读取来源和状态处理分清 P1/P2，仍归同源事件家族。[案例校准和开发暴露](../classification/development.md)

`fault_review` 的参考重点是从原事件归纳摘要、索引近邻及维护变体和来源。项目内 `fault_pattern` 继续用既有证据包和作用域规则。外部 `ascend-op-fault-patterns` 用于具体定义、范围、判据及近邻对照，`ascend-op-issue-analysis` 用于连接代码证据和运行声称。CANNBot 的尾块卡用于构造对齐与非对齐对照和观察点，支持区分尾块丢失与越域处理。各项采纳以当前模式对应的原件和验证项为依据。[具体参考与取用范围](../classification/TERMS_AND_REFERENCES.md)
